## Deskripsi

Kalkulator postfix adalah jenis kalkulator yang menggunakan notasi postfix untuk mengevaluasikan input dari pengguna. Notasi postfix dipilih karena suatu expresi yang dibuat menggunakan notasi postfix lebih mudah diproses dan lebih efisien daripada jika menggunakan notasi infix.

Program kalkulator postfix ini mendukung seluruh kapabilitas dasar kalkulator sehari-hari, serta dilengkapi dengan fungsi-fungsi trigonometri. Fitur riwayat hasil kalkulasi akan diimplementasikan selanjutnya.

Program kalkulator postfix ini dibuat menggunakan bahasa pemrograman Java 21 dan dengan editor Apache NetBeans IDE 24.
